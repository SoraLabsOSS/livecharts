# @livecharts/core

Framework-agnostic canvas real-time chart engine for LiveCharts.

No React dependency. Use from Vue / vanilla via `LiveChartEngine`, or through `livecharts/react`.

## Attribution

Based on [Liveline](https://github.com/benjitaylor/liveline) by Benji Taylor (MIT). See `LICENSE.liveline`.

## Build

```bash
bun run build --filter=@livecharts/core
bun run test --filter=@livecharts/core
```
